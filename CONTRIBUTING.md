# Contributing

The rules for changing this repository — what may and must never be in it, how
the code is built, and how commits and pull requests are written — live in one
place: [CLAUDE.md](CLAUDE.md). They apply to people and to coding agents alike.

The short version: this repository is public, so everything you push, every
commit message and every pull request description is readable by anyone, for
good. Run `node scripts/check-public-safety.mjs` before you push.
